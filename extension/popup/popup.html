Setup required

Downloads are done by a small helper app on your computer that runs yt-dlp and ffmpeg. It isn't installed yet, or the browser can't reach it.

  1. Install Python 3 (python.org), then run pip install -U yt-dlp.
  2. Install ffmpeg (Windows: winget install Gyan.FFmpeg, macOS: brew install ffmpeg).
  3. Copy this extension's ID:
  4. In the project's host folder run install.bat (Windows) or install.sh (macOS / Linux) and paste the ID when asked.
  5. Restart the browser completely, then press Check again.
